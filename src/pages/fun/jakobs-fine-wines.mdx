The first time I saw [this demo](https://live-transitions.pages.dev/), I was completely blown away, and I knew I wanted to check out the thing that made it possible - the [view transition API](https://developer.mozilla.org/en-US/docs/Web/API/View_Transition_API). Fast-forward a couple of years, and I've gotten to speak about this API at most of Scandinavia's biggest software conferences.

In that talk I show off a demo I've made. It's similar to the one that inspired me, but instead of Astro it just uses pure HTML and CSS! If you're using a browser that supports the view transition API (ie. not Firefox), give it a look: [https://jakob.vin](https://jakob.vin)

If you wanna see what the code looks like, it's of course available [on GitHub](https://github.com/itzjacki/view-transitions-wine-shop)!

## I want to build something similar

If you want to create something that uses the view transition API extensively, you're gonna wanna check out these resources:

- _[View transitions: Handling aspect ratio changes](https://jakearchibald.com/2024/view-transitions-handling-aspect-ratio-changes/)_, a blog post by Mozilla dev Jake Archibald that tells you exactly why your view transitions keep breaking.
- _[Cranking View Transitions up to 11](https://youtu.be/QA5f2loqtM4)_ by Chrome DevRel Bramus Van Damme. A talk that goes into more depth on how to work with view transitions in a practical manner.

## Why an online wine store?

I figured that a mock-webstore would be a good choice for the demo, and I am a big wine nerd who happened to own a domain comprised of my own name and the Norwegian word for wine already 🍷
